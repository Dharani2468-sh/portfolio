Dharani Portfolio - separate files

Files:
- index.html: portfolio page content/structure
- style.css: styling
- script.js: JavaScript behavior

How to use:
1. Keep all three files in the same folder.
2. Open index.html in a browser to preview the portfolio.
3. Edit HTML content in index.html, appearance in style.css, and behavior in script.js.
4. If the portfolio uses external image URLs, keep internet access enabled while previewing.
